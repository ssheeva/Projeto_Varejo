# Mini Projeto — Análise de Dados com Python
# Sobre o projeto

Análise Exploratória de Dados (AED) aplicada a uma base de varejo, utilizando Python e Pandas para transformar dados brutos em informações úteis.

O projeto aborda:

-🧹 Limpeza e tratamento dos dados;
-🔎 Identificação de nulos, duplicatas e inconsistências;
-📊 Estatística descritiva;
-📈 Agrupamento e análise dos dados;
-💡 Extração de insights.
-🛠️ Tecnologias
Python
Pandas
VS Code / Google Colab
📌 Objetivo

Preparar uma base de dados confiável para análises futuras ou criação de dashboards, aplicando conceitos de ETL e qualidade de dados.

💡 Insights

Ao final da análise, são apresentados os principais padrões encontrados na base, juntamente com possíveis problemas que permaneceram nos dados.
